## ✨ Features & Highlights

- 👾 **Authentic Retro Discord Aesthetics**: Recreates a 90s brutalist Discord user profile with flat 0px borders, Courier New monospace accents, `#18191c` box-shadow offsets, and classic Discord blurple (`#5865f2`).
- 🔗 **Clean Directory URLs**: All sections run as clean directories (`/about/`, `/skills/`, `/education/`, `/projects/`, `/certificates/`, `/contact/`, `/socials/`) without `.html` extensions.
- 📱 **100% Fully Responsive**: Pixel-perfect adaptation across ultra-wide monitors, laptops, tablets, and mobile devices.
- ⚡ **Zero Heavy Frameworks**: Pure HTML5, CSS3, and Vanilla JavaScript for blazing-fast load times and zero compilation dependencies.
- 🏆 **Divided Credentials System**: Segregated Honors & Competitive Awards from verified Technical Certifications with official verification badges and preview modals.
- 📦 **Interactive Projects Browser**: Filterable portfolio feed (Machine Learning, Deep Learning, Web Apps, Research) featuring an instant modal dialog for in-depth architecture and tech stack reviews.
- 🔍 **Comprehensive SEO & OpenGraph**: Canonical URLs, rich social preview cards, Twitter cards, and structured metadata for high discoverability.

## 🌐 Clean URL Architecture

The portfolio implements clean directory URLs for clean presentation across all modern browsers:

| Route | Directory Path | Page Description |
| :--- | :--- | :--- |
| `/` | `index.html` | Profile overview, bio, badges & activity |
| `/about/` | `about/index.html` | In-depth professional bio & career goals |
| `/skills/` | `skills/index.html` | ML, data science, and development tech stack |
| `/education/` | `education/index.html` | Academic journey & education timeline |
| `/projects/` | `projects/index.html` | Machine learning models, tools & codebases |
| `/certificates/` | `certificates/index.html` | Verified honors, awards & industry certificates |
| `/contact/` | `contact/index.html` | Direct email, Discord, Matrix, and LinkedIn |
| `/socials/` | `socials/index.html` | Discord-style links hub (Linktree alternative) |
| `/blog/` | `blog/` | Technical blog and articles |

> *Note: All routes are structured as clean, SEO-friendly directory endpoints with dedicated `index.html` entry points, fully indexed in `sitemap.xml`.*

## 🎯 Setup & Local Development

### 1. Clone the Repository
```bash
git clone https://github.com/SahooShuvranshu/SahooShuvranshu.github.io.git
cd SahooShuvranshu.github.io
```

### 2. Launch Local Development Server
Because project data (`projects.json`, `certificates.json`, `awards.json`) is dynamically loaded via the `fetch()` API, run a local web server to avoid CORS file protocol restrictions:

**Using Python 3:**
```bash
python -m http.server 8000
```

**Using Node.js (`npx`):**
```bash
npx serve .
```

### 3. Open in Browser
Visit `http://localhost:8000` to test pages and clean directory routes locally.

## 🎨 Customization Guide

### Updating Projects & Credentials
All data-driven sections load from clean JSON structures in `media/`:
- **Projects**: Edit `media/projects/projects.json` to add new models, repositories, and demos.
- **Certificates**: Edit `media/certificates/certificates.json` with your credential IDs, issuers, and verification links.
- **Awards**: Edit `media/awards/awards.json` with competitive rankings, dates, and descriptions.

### Modifying Discord Badges
Profile badges are SVG assets located in `images/badges/`. Custom role pills and status indicators can be configured via CSS variables in `css/discord-retro.css`.
